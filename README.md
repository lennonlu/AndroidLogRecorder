# Android 自动日志采集 & 录屏工具

插上手机即开始采集，无需任何配置。

## 功能

| 功能 | 说明 |
|------|------|
| 日志采集 | 自动保存当天 Logcat，过滤历史日志 |
| 崩溃归档 | 自动识别 FATAL/ANR/Native crash，含堆栈上下文写入 `crashes.log` |
| 自动录屏 | 普通设备约 60s 自动续录，可选横屏/竖屏，保持比例且短边最大 720 |
| 时间戳+触摸 | 录屏叠加实时时间 + 触摸圆点，方便回放定位 |
| 存储预警 | 设备空间 <500MB 自动告警 |
| 即时停止 | Ctrl+C 一次响应，回车确认退出 |
| 跨午夜采集 | 长时间运行穿越 00:00 自动切换日志日期 |
| 模拟器快连 | 一键连接雷电、夜神、逍遥、MuMu、BlueStacks，或批量尝试 |
| 逍遥兼容录屏 | DX 渲染下使用 scrcpy 连续录制，停止后按关键帧无损分段 |
| 自动打开目录 | 停止后打印绝对路径并打开本次采集文件夹 |

## 环境要求

- **Windows** + **USB 调试** 已开启的安卓手机
- ADB 已内置，无需额外安装
- exe 版无需 Python；源码版需 Python 3.8+

## 文件说明

```
├── AndroidLogger.exe     ← 独立可执行（推荐）
├── android_logger.py     ← Python 源码
├── 启动采集.bat           ← 双击：日志 + 录屏
├── 仅采集日志.bat         ← 双击：仅日志
├── adb.exe / AdbWin*.dll ← ADB 1.0.41（已内置）
└── scrcpy-win64-v4.1/    ← 逍遥兼容录屏与 FFmpeg 无损分段组件
```

## 使用方法

**双击启动**：`启动采集.bat`（全功能）或 `仅采集日志.bat`（仅日志）。启动后可选择快速连接常见模拟器；多设备时自动弹出设备选择菜单。

模拟器快速连接支持：

- 雷电模拟器：`emulator-5554` / `127.0.0.1:5555`
- 夜神模拟器：`127.0.0.1:62001`
- 逍遥模拟器：`127.0.0.1:21503`
- MuMu 模拟器：`127.0.0.1:7555`
- BlueStacks：`127.0.0.1:5555`

连接前会先检测本机端口，未启动的模拟器会快速跳过；连接失败时仍会继续扫描 USB 和已经在线的设备。

### 逍遥模拟器录屏

逍遥模拟器建议使用 **DX 渲染模式**。选择逍遥设备后，工具会自动改用 scrcpy 连续录屏；Logcat、崩溃和 ANR 检测仍与其他设备完全相同并行运行。

- 采集期间只启动一次 scrcpy，视频没有每分钟重启造成的空档
- 停止采集后使用 FFmpeg `-c copy` 按关键帧切成约 60 秒一段
- 不重新编码，不降低画质；因切点必须落在关键帧上，单段时长不保证严格为 60 秒
- 处理成功后输出 `screen_时间.mp4`；处理失败时保留 `screen_raw_时间.mkv`
- `scrcpy_record.log` 保存兼容录屏组件的诊断输出

```bash
# 命令行
AndroidLogger.exe                  # 全功能
AndroidLogger.exe --no-record      # 仅日志
AndroidLogger.exe -s 设备序列号     # 指定设备
AndroidLogger.exe -o D:\captures   # 指定输出目录
```

## 输出结构

```
captures/session_型号_日期_时间/
├── logcat_full.log      # 当天日志
├── crashes.log          # 崩溃/ANR 归档 + 堆栈
├── scrcpy_record.log    # 逍遥录屏诊断（仅逍遥模式）
├── screen_年月日时分秒.mp4 # 录屏片段
└── ...
```

## 设计要点

- **当天日志过滤**：按 MM-DD 前缀匹配，忽略缓冲区旧日志
- **录屏分段**：普通设备 60s 自动续录；逍遥连续录制并在停止后无损分段
- **自适应尺寸**：普通设备保留横屏/竖屏选择，按实际屏幕比例缩小，短边最大 720，低分辨率设备不放大
- **崩溃检测**：匹配 `FATAL EXCEPTION` / `Fatal signal` / `ANR in` 等关键词，自动写入 crashes.log（含 3-5 行上下文堆栈）
- **精确停止**：pkill 按文件名匹配，不误杀其他 screenrecord
- **触摸恢复**：停止流程优先恢复设备设置，避免 USB 断连后残留
- **批量 flush**：每 100 行写入一次，降低 IO 开销

## 停止

- **Ctrl+C** — 一次即停，自动拉取最后一段录屏，回车退出
- **拔 USB** — 自动检测断开，停止保存
